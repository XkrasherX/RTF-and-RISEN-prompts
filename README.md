# 🚀 RTF & RISEN: The Prompt Engineering Blueprint

Maximize the output quality of LLMs (ChatGPT, Claude, Gemini) by using industry-standard prompt engineering frameworks. This repository contains a curated collection of ready-to-use templates built on the **RTF** and **RISEN** methodologies.

-----

## 🧠 Why Frameworks Matter?

Standardizing your prompts reduces "AI hallucinations" and ensures consistent, high-quality results. Using these frameworks typically increases the relevance of AI responses by up to **80%**.

### 🛠 The Core Frameworks

| Framework | Components | Best For... |
| :--- | :--- | :--- |
| **RTF** | **R**ole, **T**ask, **F**ormat | Quick, actionable tasks & clear deliverables. |
| **RISEN** | **R**ole, **I**nput, **S**teps, **E**xpectation, **N**arrowing | Complex projects, deep analysis, and strategic planning. |

-----

## 🏗 Framework Breakdown

### 1\. The RTF Method ⚡

*Designed for speed and clarity.*

  * **Role:** Who should the AI be? (e.g., *Senior Copywriter*)
  * **Task:** What needs to be done? (e.g., *Write a 500-word blog post*)
  * **Format:** How should the output look? (e.g., *Markdown with H2 headers*)

### 2\. The RISEN Method 💎

*Designed for precision and depth.*

  * **Role:** Define the expert persona.
  * **Input:** Provide data, background, or reference material.
  * **Steps:** List specific instructions or a sequence of actions.
  * **Expectation:** Define what a "perfect" result looks like.
  * **Narrowing:** Set constraints (e.g., *"Do not mention X," "Limit to 3 paragraphs"*).

## 💡 Real-World Example

**Task:** Create a technical documentation outline.

**Prompt (Using RISEN):**

>   * **Role:** You are a Lead Technical Writer.
>   * **Input:** I have a Python library for web scraping.
>   * **Steps:** 1. Analyze the core features. 2. Create a logical flow. 3. Include a 'Troubleshooting' section.
>   * **Expectation:** A comprehensive Markdown outline ready for GitHub.
>   * **Narrowing:** Keep it professional. Do not use jargon without explaining it.

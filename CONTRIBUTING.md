## 💡 How Can I Contribute?

You can contribute in several ways:

* **Add New Prompts:** Share your best RTF or RISEN prompt templates.
* **Improve Existing Prompts:** Refine parameters, fix typos, or add clarity to current templates.
* **Add Examples:** Show how a template translates into a real AI output.
* **Suggest Frameworks:** If you know other powerful frameworks (like *CREATE*, *TAG*, or *PEEL*), feel free to propose them!

## 🚀 Contribution Process

To ensure a smooth workflow, please follow these steps:

### 1. Fork and Clone
Fork the repository to your GitHub account, then clone it locally:
```bash
git clone [https://github.com/YOUR_USERNAME/RTF-and-RISEN-prompts.git](https://github.com/YOUR_USERNAME/RTF-and-RISEN-prompts.git)
### 2\. Create a Branch

Create a branch for your changes. Use clear, descriptive names:

```bash
# For a new prompt
git checkout -b prompt/marketing-strategy

# For a bug fix or typo
git checkout -b fix/typo-readme
```

### 3\. Make Changes & Commit

Add your templates. Ensure you use proper Markdown formatting. Commit your changes with a clear message:

```bash
git commit -m "Add a RISEN template for SEO auditing"
```

### 4\. Push and Open a Pull Request

Push your branch to your fork:

```bash
git push origin prompt/marketing-strategy
```

Go to the original repository on GitHub and click **"Compare & pull request"**.

## 📏 Prompt Style Guidelines

To keep the repository clean and uniform, please adhere to the following standards:

### 📂 File Structure

Place your files in the appropriate folder:

  * `RTF_Templates/` — For quick, task-oriented prompts.
  * `RISEN_Templates/` — For deep, complex, and multi-step workflows.

### 🏷 File Naming Convention

Use lowercase letters and hyphens for filenames.

  * ✅ Good: `social-media-planner.md`
  * ❌ Bad: `Social Media Planner.md` or `social_media_planner.txt`

### 📝 Template Formatting

When creating a prompt file, use placeholders in brackets for variables.

**Example:**

> You are a **[Role]**. Your task is to **[Task]**. Please output the result in **[Format]**.

-----

## ✅ Pull Request Checklist

Before hitting that submit button, please verify that your PR meets these criteria:

  - [ ] The file is placed in the correct directory.
  - [ ] Filenames follow the standard `lowercase-hyphenated.md` format.
  - [ ] The template uses bracketed placeholders (e.g., `[Insert Topic Here]`) for user variables.
  - [ ] The README or examples are updated if necessary.
